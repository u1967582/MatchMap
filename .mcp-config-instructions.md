# Mapbox MCP Server Configuration

Este proyecto utiliza el Mapbox MCP (Model Context Protocol) Server para proporcionar herramientas adicionales de Mapbox a Claude Code.

## Configuración

Para habilitar el servidor MCP de Mapbox en Claude Code, agrega la siguiente configuración a tu archivo de configuración de MCP:

**Ubicación del archivo:**
- **macOS/Linux**: `~/.config/claude-code/mcp_settings.json`
- **Windows**: `%APPDATA%\claude-code\mcp_settings.json`

**Configuración a agregar:**

```json
{
  "mcpServers": {
    "MapboxServer": {
      "command": "npx",
      "args": ["-y", "@mapbox/mcp-server"],
      "env": {
        "MAPBOX_ACCESS_TOKEN": "pk.eyJ1Ijoicm9nZXIxN2dvc3QiLCJhIjoiY21jdDlxaG9lMDNveDJqcXVsMTJvMXlvaSJ9.K41sVHLz2k0T8OI0agyp6w"
      }
    }
  }
}
```

## Herramientas Disponibles

Una vez configurado, el servidor MCP de Mapbox proporciona las siguientes herramientas:

### 1. **Geocoding (Forward)**
Convierte direcciones de texto en coordenadas geográficas.

**Ejemplo de uso:**
```
"Carrer de Pau Claris, 162, Barcelona"
→ { lat: 41.3951, lng: 2.1734 }
```

**Casos de uso en MatchMap:**
- Búsqueda de bares por dirección
- Validación de direcciones al crear/editar bares
- Centrar el mapa en una dirección específica

### 2. **Reverse Geocoding**
Convierte coordenadas geográficas en direcciones legibles.

**Ejemplo de uso:**
```
{ lat: 41.3951, lng: 2.1734 }
→ "Carrer de Pau Claris, 162, 08037 Barcelona, España"
```

**Casos de uso en MatchMap:**
- Mostrar dirección del bar a partir de coordenadas
- Autocompletar dirección al agregar un bar en el mapa
- Mostrar ubicación actual del usuario en texto

### 3. **Directions API**
Calcula rutas entre dos puntos con información de distancia y tiempo.

**Ejemplo de uso:**
```
Desde: { lat: 41.3851, lng: 2.1734 }
Hasta: { lat: 41.4051, lng: 2.1934 }
→ { distance: 3.2km, duration: 8min, geometry: [...] }
```

**Casos de uso en MatchMap:**
- Función "Cómo llegar" desde ubicación actual al bar
- Calcular distancia real (no solo Haversine)
- Mostrar tiempo estimado de llegada
- Dibujar ruta en el mapa

### 4. **Search/Places**
Busca lugares por nombre o categoría cerca de una ubicación.

**Ejemplo de uso:**
```
Query: "bar", Near: { lat: 41.3851, lng: 2.1734 }
→ Lista de bares cercanos con datos de Mapbox POI
```

**Casos de uso en MatchMap:**
- Sugerir bares al agregar nuevos (verificar si ya existen)
- Autocompletado de búsqueda
- Descubrir bares populares en un área

### 5. **Static Maps**
Genera URLs de imágenes estáticas de mapas.

**Ejemplo de uso:**
```
Center: { lat: 41.3851, lng: 2.1734 }, zoom: 15
→ URL: https://api.mapbox.com/styles/v1/mapbox/streets-v11/static/...
```

**Casos de uso en MatchMap:**
- Imágenes preview del mapa para compartir
- Thumbnails de ubicación de bares
- Notificaciones con mapas estáticos

## Integración con MatchMap

### Variables de Entorno Actuales

El proyecto ya tiene configurado el token de Mapbox:

```typescript
// components/Map.tsx
const MAPBOX_ACCESS_TOKEN = process.env.EXPO_PUBLIC_MAPBOX_ACCESS_TOKEN ||
  'pk.eyJ1Ijoicm9nZXIxN2dvc3QiLCJhIjoiY21jdDlxaG9lMDNveDJqcXVsMTJvMXlvaSJ9.K41sVHLz2k0T8OI0agyp6w';
```

### Features que Pueden Beneficiarse del MCP

1. **Búsqueda de Bares (app/search.tsx)**
   - Usar geocoding para búsqueda por dirección
   - Validar y mejorar direcciones de bares

2. **Perfil de Bar (app/bar-profile/[barId].tsx)**
   - Botón "Cómo llegar" con Directions API
   - Mostrar tiempo estimado de llegada
   - Dibujar ruta en minimap

3. **Mapa Principal (components/Map.tsx)**
   - Reverse geocoding al hacer tap en el mapa
   - Dibujar rutas de navegación
   - Búsqueda por dirección

4. **Agregar/Editar Bar**
   - Geocoding para validar dirección ingresada
   - Autocompletado de direcciones
   - Verificar duplicados con Places API

```

"Calcula la ruta desde la ubicación actual del usuario hasta el bar seleccionado"

"Convierte las coordenadas {lat: 41.3851, lng: 2.1734} en una dirección legible"

"Busca bares cerca de 'Sagrada Familia' usando la API de Places de Mapbox"
```

## Verificar Configuración

Para verificar que el MCP server está funcionando:

1. Reinicia Claude Code después de agregar la configuración
2. En una nueva conversación, pregunta: "¿Tienes acceso a herramientas de Mapbox MCP?"
3. Claude debería confirmar que tiene acceso a las herramientas de geocoding, directions, etc.

## Notas de Seguridad

- ⚠️ El token incluido en la configuración es visible en el código del proyecto
- 🔒 Para producción, considera usar variables de entorno o secretos
- 📊 Monitorea el uso del token en el dashboard de Mapbox
- 🔄 Rota el token periódicamente para mayor seguridad

## Cuota y Límites

Mapbox tiene diferentes límites según el plan:

- **Geocoding**: 100,000 requests/mes (free tier)
- **Directions**: 100,000 requests/mes (free tier)
- **Static Maps**: 50,000 requests/mes (free tier)

Monitorea el uso en: https://account.mapbox.com/
